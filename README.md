# Автоматизированное тестирование в 1С (Vanessa Automation)

Учебный практический проект по автоматизации тестирования бизнес-процессов в конфигурациях 1С с использованием BDD-подхода (Gherkin) и инструмента Vanessa Automation.

## 🛠 Стек технологий:
- **Платформа:** 1С:Предприятие
- **Инструмент тестирования:** Vanessa Automation
- **Язык сценариев:** Gherkin / Bgherkin
- **Система контроля версий:** Git / GitHub

## 📂 Что реализовано в проекте:
- Написание атомарных и читаемых `.feature` сценариев.
- Работа с интерфейсом 1С (заполнение форм, работа со справочниками и документами).
- Реализация экспортных сценариев (подсценариев) для переиспользования кода.
- Использование условных конструкций (`Если - Иначе`) и циклов в тестах.
- Покрытие автотестами ключевых документов (Заказы, Поступление товаров и др.).
