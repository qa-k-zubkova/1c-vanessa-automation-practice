# Автоматизированное тестирование в 1С при помощи Vanessa Automation

Репозиторий содержит примеры автотестов (сценариев поведения), разработанных в рамках практического освоения фреймворка Vanessa Automation и языка TurboGherkin для платформы 1С:Предприятие 8.

## 🚀 Стек технологий
* **Инструменты:** Vanessa Automation, 1С:Предприятие 8.3 (управляемые формы)
* **Язык сценариев:** TurboGherkin (Gherkin)
* **Среда разработки:** Vanessa Automation Editor / VS Code
